# FashionNewz

Static Netlify-ready starter site for fashionnewz.netlify.app.

## Included
- Responsive editorial homepage
- Fashion / Beauty / Hair / Shopping navigation
- 6 original starter brand guides:
  - Rent the Runway
  - Plant Therapy
  - Bexley
  - Huda Beauty
  - Favorite Daughter
  - UNice Hair
- About, Contact, Affiliate Disclosure, Privacy, Terms pages
- No build step required

## Deploy
Upload this folder to Netlify, or connect the repository containing it.

## Before launch
1. Replace placeholder contact details.
2. Replace the starter privacy/terms language with policies matching your actual setup.
3. Add your analytics/consent tooling if used.
4. Add verified affiliate links only where you have approved programs.
5. Replace CSS-generated placeholder hero blocks with licensed/editorial imagery.
6. Add 24 more brand guides using the same article template.

## Important
The starter articles are editorial drafts. Verify current pricing, availability, product claims, policies and brand facts against primary sources before publication.
